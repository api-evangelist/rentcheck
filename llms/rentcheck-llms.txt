# RentCheck

> RentCheck is a resident-led property inspection platform. Property managers use it to run guided move-in, move-out, routine, and maintenance inspections that residents complete from their smartphone, generating time-stamped photo reports. The RentCheck REST API lets developers pull property and resident data, schedule and create inspections, and act on inspection results across property management, maintenance, and insurance use cases.

## API

- [RentCheck REST API — developer docs](https://developers.getrentcheck.com/): Stoplight Elements reference for the RentCheck REST API (OpenAPI 3.1). Base URL https://prod-public-api.getrentcheck.com. Auth: Bearer JWT access token plus x-app-id and x-app-secret application headers.
- [OpenAPI specification (doc_specs.yml)](https://rentcheck-lambdas-static-files.s3-us-east-2.amazonaws.com/doc_specs.yml): 160 paths, 217 operations, 195 schemas. Resource families: Units, Buildings, Communities, Inspections (+ V2), Inspection Templates, Inspection Features, Residents (V2/V3), Leases, Users, Teams, Work Orders, Maintenance Reports/Flags, Automations, Subscriptions.

## Notes

- Pagination: page_size (max 250) + zero-based page_number; responses carry data, count, total_results.
- Rate limits: 8/sec, 256/min, 1024/10-min; HTTP 429 on exceed.
- Errors: flat JSON envelope { "status": <int>, "error": "<string>" } — not RFC 9457.
- No public MCP server, SDK/package, CLI, or status page found as of 2026-07-20.
